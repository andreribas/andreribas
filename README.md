## André Ribas
Backend engineer with 10+ years of experience, most of it at EBANX — one of Latin America's largest payment platforms. I've worked across core payment processing, SRE, fraud prevention, and client-facing products.
I care a lot about writing simple, readable code that solves real problems. Not clever code. Not over-engineered abstractions. Code that a peer working asynchronously — or an AI — can read, understand, and change without friction.
Currently based in Curitiba, Brazil. Deeply aligned with open-source and a decentralized web.

## What's here
- c-library — A college project that got out of hand in the best way. The assignment was a simple library CRUD system; I used it as an excuse to build a functional MVC framework from scratch in PHP — router, template engine, models, the whole thing. Each early commit implements one piece of the framework, so the git history reads like a walkthrough. Built purely for the learning loop.
- dotfiles — My personal environment configuration. A workspace that reflects how I think: minimal, organized, nothing unnecessary.
- chip8 — A CHIP-8 emulator in JavaScript. A classic low-level exercise I did to better understand how interpreters and display rendering work at a hardware-adjacent level.

## How I work

- I use AI as a cognitive tool: stress-testing my own logic, clearing mechanical friction, finding blind spots before code review
